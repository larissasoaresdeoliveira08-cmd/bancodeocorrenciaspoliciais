Como funciona
  1. O administrador (quem cadastra os modelos) entra aqui com e-mail e senha e cadastra ou edita as ocorrências nas abas Modelos e Novo.
  2. Tudo o que ele salva vai para a nuvem e aparece sozinho para todos os policiais.
  3. Os policiais não precisam de login: abrem o link, escolhem o modelo no Gerar, preenchem, revisam e copiam. O histórico de cada um fica no próprio aparelho.

Revisão com IA (opcional)

A chave e o modelo ficam guardados somente neste aparelho. O texto enviado vai para o Google Gemini; evite dados pessoais reais.

Como obter a chave

  1. Acesse aistudio.google.com e entre com uma conta Google.
  2. Clique em Get API key (Obter chave de API) e depois em Criar chave de API.
  3. Copie a chave gerada (começa com “AIza”) e cole acima.
  4. Use na aba Gerar, no quadro de revisão, botão Revisar com IA.

Backup

Guarde uma cópia dos modelos e do histórico deste aparelho. Restaurar sempre mescla com o que já existe, sem apagar nada.

Configuração do servidor (Firebase)

Feita uma única vez pelo administrador. No site publicado, preencha as constantes FIREBASE_CONFIG e ADMIN_EMAILS no início do código — com elas preenchidas, este quadro some. Os campos abaixo servem só para testar neste aparelho.

Passo a passo

  1. Acesse console.firebase.google.com e crie um projeto (gratuito).
  2. Em Authentication › Método de login, ative E-mail/senha.
  3. Em Authentication › Usuários, clique em Adicionar usuário e crie o e-mail e a senha do administrador.
  4. Em Authentication › Configurações › Ações do usuário, desmarque Ativar criação (inscrição), para ninguém mais criar conta.
  5. Em Firestore Database, crie o banco no local southamerica-east1 (São Paulo).
  6. Na aba Regras do Firestore, cole as regras abaixo trocando o e-mail pelo do administrador e publique.
  7. Em Configurações do projeto › Geral, adicione um app Web e copie apiKey e projectId.
rules_version='2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /catalogo/{doc} {
      allow read: if true;
      allow write: if request.auth != null
        && request.auth.token.email in ['admin@exemplo.com'];
    }
  }
}

Para ter mais de um administrador, coloque os e-mails separados por vírgula na lista, ex.: ['a@x.com', 'b@x.com'].

Segurança

  • Só os e-mails autorizados nas regras do banco conseguem criar, editar ou excluir modelos — mesmo que alguém tente por fora do site.
  • Os modelos são públicos para leitura: nunca coloque dados pessoais reais neles (use campos como [VITIMA] e [CPF]).
  • Os textos gerados pelos policiais ficam só no aparelho de cada um e não vão para a nuvem.
  • Use uma senha forte e saia da conta em aparelhos compartilhados.

Ferramenta de apoio à redação. Não cria fatos nem dispensa a revisão do relato pelo policial responsável.
